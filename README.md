## Public boundary

The DocX source repository remains private. This repository intentionally contains only sanitized planning, primary-source research, prototypes, architecture explanations, reproducible measurements, and small curated code excerpts suitable for a public portfolio.

The resulting site will demonstrate DocX without publishing proprietary analyzer internals, raw extension source, full source maps, regulatory or security-detail surfaces, private issue references, or raw report payloads.
